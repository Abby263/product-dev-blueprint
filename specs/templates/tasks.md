# Task Checklist

## Product

- [ ] Confirm problem, audience, buyer, and success criteria.
- [ ] Confirm MVP boundary and non-goals.
- [ ] Confirm follow-up questions and assumptions.
- [ ] Update README or setup docs when product behavior changes.

## Architecture

- [ ] Update canonical schema first when new generated data is needed.
- [ ] Update intake UI and owner labels.
- [ ] Update deterministic generators.
- [ ] Check HLD, LLD, schema, APIs, security, compliance, infra, and scaling output.

## Engineering

- [ ] Keep changes on a branch.
- [ ] Run `npm run typecheck`.
- [ ] Run `npm run build`.
- [ ] Create PR with summary and test notes.
- [ ] Merge after checks pass.
- [ ] Confirm production deployment.
